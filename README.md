# Addchem Enterprises — aesthetic static website

Built for independent hosting on Cloudflare with the supplied Addchem catalogue.

## Contents
- `index.html` — main site
- `styles.css` — visual system + responsive layout
- `script.js` — catalogue search, WhatsApp enquiry, cursor-responsive particle background
- `products.json` — supplied 4,037-record catalogue
- `products/` — one SEO-friendly page per catalogue record
- `assets/logo.png` — supplied Addchem logo
- `sitemap.xml` — home + all product URLs
- `robots.txt` — crawler instructions
